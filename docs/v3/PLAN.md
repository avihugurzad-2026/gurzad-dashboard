# תוכנית מבנה ומסכים — Gurzad v3

## 1. ארכיטקטורה
- **Frontend:** Vite + React + TypeScript, `motion` לאנימציות, `lucide-react` לאייקונים. CSS עם טוקנים (בלי ספריית UI גנרית).
- **Backend:** Supabase (פרויקט `gurzad-all-in-one`, אובייקטים בתחילית `gd_`) — משתמשים, Postgres עם RLS, Storage לתמונות. פונקציות Vercel ב‑`api/`: OTP והזמנות דרך Resend, וואטסאפ (Kapso), בדיקות סטטוס ו‑Gemini.
- **מצב הדגמה:** בלי משתני סביבה האפליקציה רצה על נתוני דוגמה ב‑localStorage (קוד OTP להדגמה: `123456`). עם `VITE_SUPABASE_URL` + `VITE_SUPABASE_ANON_KEY` היא עוברת לסופבייס בלי שינוי קוד.
- **מודל נתונים:** `gd_workspaces`, `gd_memberships (role: owner|editor|viewer, areas[])`, `gd_invites`, `gd_otp`, ו‑`gd_records (collection, data jsonb)` גנרית — כמו `entities` בגרסה הקודמת, כך שסוג רשומה חדש לא דורש migration. תמונות ב‑bucket `gd-property-photos`.
- **v2 הישן** (Express + וואלט Obsidian) עבר ל‑`legacy/` כמו שהוא. הסנכרון מהוואלט יכול לחזור כמייבא אל `records`.

## 2. ניווט
- **דסקטופ (≥1200):** פס עליון: לוגו · ניווט גלולה לתחומים (סקירה / בית / עסקים / השקעות) · חיפוש · התראות · משתמש. פס אייקונים בצד ימין: וואטסאפ, סטטוס, צוות, הגדרות. תת‑ניווט של התחום כגלולה שנייה בראש התוכן.
- **אייפד (768–1199):** אותו פס עליון; הפס הצדדי מצטמצם לאייקונים; גריד 2 עמודות.
- **מובייל (<768):** טאב‑בר תחתון (סקירה, בית, עסקים, נכסים, עוד) + תת‑ניווט נגלל אופקית. כפתור "+" צף להוספה מהירה. כל הטפסים הם bottom sheet.
- היררכיה: תחום → אזור → רשומה. לא יותר משלוש רמות.
