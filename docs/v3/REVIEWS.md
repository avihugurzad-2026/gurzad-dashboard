# ביקורות — עיצוב ואנימציה (v3)

הסקילים `design-review`, `improve-animations`, `choreograph`, `review-animations` לא היו מותקנים בסשן; הביקורות בוצעו ידנית לפי כוונתם. `emil-design-eng` היה מותקן ושימש כמסגרת לביקורת האנימציה.
הבדיקה נעשתה על צילומי מסך אמיתיים ב־1440×900 (דסקטופ), 820×1180 (אייפד) ו־390×844 (מובייל), בהיר וכהה.

## 1. ביקורת עיצוב (design-review) — מה נמצא ומה תוקן

| ממצא | תיקון |
|---|---|
| הגרף בעמוד העסק נמתח לגובה עצום בכרטיס רחב | `BarChart` מקבל רוחב לוגי; כרטיס רחב = 820 |
| כיוון הזמן בגרפים היה שמאל→ימין בתוך ממשק RTL | החודש הישן מימין, החדש משמאל; גם sparkline ורצועת הנקודות |
| כרטיסי נכס בלי תמונה השתמשו כולם בגרדיאנט הגיבור (3 גרדיאנטים במסך) | מילוי מפוספס שקט; גרדיאנט אחד בלבד למסך |
| פסי "טיקים" בכרטיס הגיבור של הבית היו קישוט אקראי | מציגים הוצאה אמיתית לכל יום בחודש |
| מובייל: שלושה־ארבעה כרטיסי KPI בעמודה אחת דחקו את התוכן מתחת לקפל | KPI בזוגות (`sm-6`), ספרה 21px, בלי אייקון |
| מובייל: טאב פעיל בתת־ניווט נחתך בקצה | גלילה אוטומטית לטאב הפעיל + התת־ניווט נמתח עד קצה המסך |
| אייפד: תווית "מצב הדגמה" נשברה לשתי שורות, sparkline נדחס על הכותרת | מוסתרים מתחת ל־1200px |
| כהה: טאב־בר תחתון ולוגו בצבע מנטה בהיר, טאב פעיל בלי ניגודיות | רקע יער קבוע בשני המצבים, טאב פעיל מנטה־100 עם טקסט כהה |
| כהה: תגיות תחום וצבעי "גוון לתחום" מתחת ל־4.5:1 | גווני תחום בהירים למצב כהה |
| כהה אוטומטי (לפי מערכת): בועת צ׳אט ותגית info נשארו בצבעי בהיר | עברו לטוקנים `--accent` / `--link` |
| נתוני הדוגמה הציפו את "דורש תשומת לב" ב־6 התראות זהות | תוקנו נתוני הדוגמה; הרשימה מוגבלת ל־7 וממוינת |
| אין גלילה אופקית באף מסך ובאף רוחב | נבדק אוטומטית (`scrollWidth - clientWidth = 0`) |

## 2. ביקורת אנימציה (emil-design-eng / review-animations)

| לפני | אחרי | למה |
|---|---|---|
| כל מעבר בין תתי־טאבים הריץ מחדש cascade של כרטיסים (320ms + stagger) | cascade רק בכניסה ראשונה לעמוד; מעבר טאב = fade של 140ms בלי תזוזה (`TabBody`) | פעולה שחוזרת עשרות פעמים ביום לא מקבלת כוריאוגרפיה |
| עמודות הגרף הנפישו `y` ו־`height` (מאפייני SVG, main thread) | `scaleY` עם `transform-origin: bottom` | רק transform/opacity |
| מד התקדמות 700ms | 500ms, `scaleX` | מהיר מרגיש מגיב; transform בלבד |
| — | גלולת ניווט נעה עם `layoutId` וספרינג `420/34` (כמעט בלי bounce) | תנועה על המסך = ease‑in‑out/ספרינג שקט; דשבורד מקצועי, לא קופצני |
| — | Sheet: כניסה 340–420ms בעקומת drawer `cubic-bezier(.32,.72,0,1)`, יציאה 200ms | יציאה מהירה מכניסה |
| — | Toast: כניסה 260ms מ־`scale .96`, יציאה 140ms | אף פעם לא מ־`scale(0)` |
| — | כל לחיץ: `:active { scale(.97) }` ב־140ms | משוב מיידי |
| — | סימון פריט קניות: שינוי מיידי, רק ה־✓ מצטייר ב־180ms | הפעולה הכי תכופה באפליקציה |
| — | Popover התראות: `transform-origin` בפינת הכפתור | נפתח מהטריגר |
| — | Hover רק תחת `@media (hover: hover) and (pointer: fine)` | בלי hover תקוע במגע |
| — | אין `transition: all` באף מקום; רק מאפיינים מפורשים | |
| — | `prefers-reduced-motion`: `MotionConfig reducedMotion="user"` + כלל CSS; Sheet עובר ל־fade | פחות תנועה, לא אפס משוב |

### כוריאוגרפיה (choreograph)
סדר הכניסה לעמוד: כותרת (מיידית) → כרטיס גיבור → "דורש תשומת לב" → כרטיסי תחום → רשימות, 40ms בין כרטיס לכרטיס. בתוך כרטיס: המספר מופיע עם הכרטיס, המד והעמודות מתמלאים 60–80ms אחריו (המבט הולך קודם למספר, אחר כך להקשר). אין חסימת אינטראקציה בזמן הכניסה.
