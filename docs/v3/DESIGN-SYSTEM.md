# מערכת עיצוב — Gurzad v3 ("חממה")

> נבנתה מהפלטה שאביהו שלח (6 גוונים ירוקים) ומשתי ההשראות: דשבורד פינטק בהיר עם ניווט "גלולה" שחורה ועמודות מפוספסות, ודשבורד בריאות רך עם כרטיסי גרדיאנט וספרות בסגנון dot‑matrix. לקחנו מהן **שפה**, לא מיתוג, שמות או תוכן.
> המקור בקוד: `src/styles/tokens.css`. כל צבע/מרווח/משך זמן בקוד עובר דרך טוקן — החלפת פלטה = עריכת קובץ אחד.

## 1. רעיון מנחה
**"פנקס ירוק"** — מסמך נייר רגוע (רקע `#F9FCF8`) שעליו "גלולות" יער כהות מסמנות פעולה ומיקום, והמספרים החשובים נכתבים בספרות נקודות כמו לוח תצוגה. שלושה תחומים (בית / עסקים / השקעות) חולקים מערכת אחת, וכל תחום מקבל "גוון מוביל" מתוך אותה פלטה כדי שיהיה ברור איפה אני בלי להוסיף צבעים זרים.

### נגזרות (מחושבות מהבסיס)
- `--surface: #FFFFFF` כרטיסים; `--surface-2: #F2F7F1` שדות/שורות; `--line: #DCE8DF` גבולות hairline; `--ink: #0F3D2E`; `--ink-2: #3D5A4E` טקסט משני (ניגודיות 7.4:1 על paper); `--ink-3: #6B8277` מטא (4.6:1).
- **סטטוס** (חייב להיות ברור גם ליד כל הירוק): הצלחה = `--forest-700`; אזהרה `--amber-600 #B45309` / רקע `#FDF3E1`; סכנה `--red-600 #B42318` / רקע `#FDECEA`; מידע = `--sage-500`. **תמיד אייקון + טקסט**, לעולם לא צבע לבד.
- **גוון לתחום:** בית = `sage-500`, עסקים = `forest-700`, השקעות = `#2F6F5E` (teal-forest, נגזר). מופיע רק בפס עליון דק, באייקון התחום ובגרדיאנט כרטיס הגיבור.
- **גרדיאנט גיבור** (השראה 2): `radial-gradient` של mint-300 → sage-500 → forest-700 עם טשטוש רך ו‑grain עדין. משמש בכרטיס אחד לכל מסך לכל היותר.
- **מצב כהה:** רקע `#08201A`, משטח `#0E2B22`, קו `#1E4236`, דיו `#E6F2EA`. הגלולה הפעילה מתהפכת ל‑mint-300 על דיו כהה.

## 3. טיפוגרפיה
- **Google Sans** (Google Fonts, כולל subset עברי) — 400/500/700. מרווח אותיות 0 (עברית).
- **Doto** (Google Fonts, dot‑matrix) — **רק** לספרות גיבור (מספר אחד‑שניים למסך), השראה מדשבורד הבריאות. ליד כל ספרת Doto יש תווית רגילה, ו‑`aria-label` עם הערך המלא.
- ספרות: `font-variant-numeric: tabular-nums`, `Intl.NumberFormat('he-IL')`, ₪ דרך `currency: 'ILS'`.

## 4. ריווח, רדיוס, צל
- סקאלת 4: `--s-1:4 --s-2:8 --s-3:12 --s-4:16 --s-5:20 --s-6:24 --s-8:32 --s-10:40 --s-12:48`.
- רדיוס: `--r-sm:10` שדות, `--r-md:16` כפתורים‑כרטיסים קטנים, `--r-lg:24` כרטיסים, `--r-xl:32` כרטיס גיבור, `--r-pill:999`.
- צל: כמעט אין. `--shadow-1: 0 1px 2px rgb(15 61 46 / .06)` לכרטיסים, `--shadow-pop: 0 12px 32px -8px rgb(15 61 46 / .22)` לתפריטים/שיטים בלבד.
- גריד: מובייל 1 עמודה, 16px שוליים; אייפד (≥768) 2 עמודות, 24px; דסקטופ (≥1200) 12 עמודות, רוחב מקסימלי 1360.

## 5. תנועה
- משכים: `--t-fast:140ms` (hover/press), `--t-base:220ms` (פתיחה/מעבר), `--t-slow:380ms` (שיט/מסך).
- easing: `--ease-out: cubic-bezier(.22,1,.36,1)` כניסה; `--ease-in-out: cubic-bezier(.65,0,.35,1)` הזזה; ספרינג (motion) `stiffness 420, damping 34` לגלולה הנעה.
- כללים: כניסה תמיד מ‑`scale .97 + opacity 0`, לא מ‑0. לחיצה = `scale .97`. בלי אנימציה לפעולות שחוזרות עשרות פעמים ביום (סימון פריט קניות = מיידי + טיק קצר בלבד). `prefers-reduced-motion` מבטל תזוזות ומשאיר fade.

## 7. RTL ונגישות
`<html lang="he" dir="rtl">`; רק logical properties; אייקוני כיוון מתהפכים; מחרוזות מעורבות ב‑`<bdi>`; מטרות מגע ≥ 44px; פוקוס נראה (טבעת forest-700 2px + offset); ניגודיות ≥ 4.5:1 לכל טקסט; ניווט מקלדת מלא בשיטים (Esc סוגר, פוקוס נלכד).
